## 3. С какими сложностями столкнулись

1. **Сложность:** Синхронизация состояния текста в `OutlinedTextField` с внутренним полем объекта `User`.
   - **Решение:** Применен метод копирования данных `user = user.copy(name = newName)`, что позволяет сохранять неизменяемость (immutability) модели и триггерить точечную рекомпозицию зависящих от `name` компонентов.

2. **Сложность:** Плавная анимация изменения параметров кнопки без блокировки UI-потока.
   - **Решение:** Использованы специализированные функции анимации Compose: `animateColorAsState` для цвета контейнера и `animateFloatAsState` со спецификацией `spring()` для коэффициента масштабирования.

## 5. Ответы на контрольные вопросы для защиты

### 1. Что такое Jetpack Compose и в чём его отличие от XML-вёрстки?
**Ответ:** Jetpack Compose — декларативный UI-фреймворк для Android. В отличие от императивного XML-подхода, где программист вручную создавал View-элементы и синхронизировал их свойства с состоянием модели, в Compose UI автоматически обновляется сам в ответ на изменения состояния через механизм рекомпозиции.

### 2. Что такое `@Composable`-функция?
**Ответ:** Это специальная функция Kotlin, помеченная аннотацией `@Composable`. Она сообщает компилятору Compose, что функция предназначена для преобразования данных в узлы пользовательского интерфейса. Такие функции вызываются только в контексте других `@Composable`-функций.

### 3. Что такое `Modifier` и приведите примеры его использования.
**Ответ:** `Modifier` — это неизменяемый объект для декорирования или расширения поведения элементов интерфейса. Примеры:
- `.size(120.dp)` — установка фиксированного размера;
- `.clip(CircleShape)` — обрезка по форме круга;
- `.background(Color.Blue)` — заливка фона;
- `.padding(16.dp)` — внешние или внутренние отступы;
- `.clickable { ... }` — реакция на касания.

### 4. Как управлять состоянием в Compose? Что такое `remember`?
**Ответ:** Состояние в Compose управляется с помощью объектов `State<T>` и `MutableState<T>` (например, `mutableStateOf(value)`). Функция `remember` сохраняет этот объект в памяти дерева рекомпозиции, предотвращая сброс значения при повторных вызовах функции. Для сохранения состояния при смене конфигурации (повороте экрана) применяется `rememberSaveable`.

### 5. Как работает рекомпозиция в Compose?
**Ответ:** Рекомпозиция — это процесс повторного выполнения Composable-функций при изменении значений состояния, которые они читают. Compose оптимизирует этот процесс, обновляя лишь те узлы, параметры которых изменились, пропуская статичные ветви дерева.

### 6. В чём разница между `Column` и `Row`?
**Ответ:** `Column` размещает дочерние элементы последовательно по вертикали (сверху вниз). `Row` размещает дочерние элементы последовательно по горизонтали (слева направо). Оба контейнера поддерживают выравнивание (`alignment`) и распределение пространства (`arrangement`).

### 7. Как использовать `TextField` в Compose?
**Ответ:** `TextField` и `OutlinedTextField` работают по паттерну контролируемого компонента: принимают текущее строковое значение `value: String` и лямбду обратного вызова `onValueChange: (String) -> Unit`, в которой вызывающий компонент обновляет свое состояние:
```kotlin
var text by remember { mutableStateOf("") }
TextField(value = text, onValueChange = { text = it })
```

### 8. Что такое `Divider` (или `HorizontalDivider`) и для чего он нужен?
**Ответ:** `HorizontalDivider` — это стандартный компонент Material 3, представляющий тонкую горизонтальную разделительную линию. Используется для визуального разграничения логических блоков контента, списков и секций экрана.

### 9. Для чего нужна аннотация `@Preview`?
**Ответ:** Аннотация `@Preview` позволяет разработчику просматривать внешний вид создаваемых компонентов непосредственно в дизайнере Android Studio без необходимости развертывания приложения на физическом смартфоне или эмуляторе.

### 10. Как вынести повторяющийся код в отдельный компонент?
**Ответ:** Повторяющийся UI выносится в отдельную `@Composable`-функцию (например, в отдельный файл пакета `ui/components/`). Все варьирующиеся данные и обработчики событий передаются в нее в виде параметров, а также обязательно добавляется параметр `modifier: Modifier = Modifier` для гибкости позиционирования вызывающей стороной.
