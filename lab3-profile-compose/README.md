# Profile App — экран профиля на Jetpack Compose

## Описание проекта
Мобильное приложение представляет собой интерактивный экран профиля пользователя, разработанный на базе декларативного UI-фреймворка **Jetpack Compose** в соответствии с принципами Material Design 3.

Проект выполнен в рамках курса «Программирование мобильных устройств» и демонстрирует компонентный подход, реактивное управление состоянием, анимацию и динамическое переключение тем.

---

## Архитектура и стек технологий
- **Язык программирования:** Kotlin 2.0 (JVM 17)
- **UI-фреймворк:** Jetpack Compose (BOM 2024.06.00)
- **Дизайн-система:** Material 3
- **Архитектурный паттерн:** Unidirectional Data Flow (UDF)
- **Среда разработки:** Android Studio Jellyfish / Koala
- **Минимальная версия Android:** API 24 (Android 7.0)
- **Целевая версия Android:** API 34 (Android 14)

---

## Функциональные возможности
- **Круглый аватар** со стильной границей, тенью и иконкой Material Icons (`Icons.Default.Person`).
- **Блок персональной информации:** отображение полного имени, статуса и динамического бейджа с количеством подписчиков.
- **Интерактивное редактирование имени:** компонент `OutlinedTextField` с мгновенной рекомпозицией и синхронизацией данных.
- **Кнопка «Подписаться / Отписаться»:**
  - Плавная смена цвета и пружинная анимация масштабирования (`animateColorAsState`, `animateFloatAsState`).
  - Автоматический пересчёт количества подписчиков (+1 / -1) в реальном времени.
- **Кнопка «Сброс»:** мгновенный возврат всех полей профиля и счётчика к значениям по умолчанию.
- **Интерактивный счётчик нажатий:** карточка с числовым индикатором и кнопкой инкремента.
- **Динамическая тема оформления:** переключатель `Switch` для мгновенного перехода между светлой и тёмной темами без перезапуска Activity.

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/TheLegendMaster2023/mobile-dev-labs.git
   ```
2. **Перейдите в директорию лабораторной работы:**
   ```bash
   cd mobile-dev-labs/lab3-profile-compose
   ```
3. **Откройте проект в Android Studio:**
   - Выберите `File` -> `Open...` и укажите каталог `lab3-profile-compose`.
4. **Синхронизируйте проект с Gradle** (`Sync Project with Gradle Files`).
5. **Запустите приложение на устройстве или эмуляторе** (`Shift + F10`).
