# Hello Compose — первое приложение на Jetpack Compose

## Описание проекта
Простое мобильное приложение для знакомства с **Jetpack Compose** — современным декларативным UI-фреймворком для платформы Android. Проект разработан в рамках курса «Программирование мобильных устройств».

В приложении реализована карточка приветствия с данными студента, стилизованная с использованием Material 3 и цепочек модификаторов (`Modifier`), а также интерактивный счётчик нажатий.

---

## Архитектура и технологии
- **Язык программирования:** Kotlin 2.0 (JVM 17)
- **UI-фреймворк:** Jetpack Compose (BOM 2024.06.00)
- **Дизайн-система:** Material Design 3 (Material3)
- **Среда разработки:** Android Studio Jellyfish / Koala
- **Минимальная версия Android:** API 24 (Android 7.0 Nougat)
- **Целевая версия Android:** API 34 (Android 14)

---

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/TheLegendMaster2023/mobile-dev-labs.git
   ```
2. **Перейдите в директорию лабораторной работы:**
   ```bash
   cd mobile-dev-labs/lab1-hello-compose
   ```
3. **Откройте проект в Android Studio:**
   - Выберите `File` -> `Open...` и укажите папку `lab1-hello-compose`.
4. **Дождитесь синхронизации Gradle** и индексации зависимостей.
5. **Запустите приложение:**
   - Выберите подключенное физическое устройство или эмулятор (например, Pixel 6, API 34).
   - Нажмите сочетание клавиш `Shift + F10` или зеленую кнопку `Run`.
