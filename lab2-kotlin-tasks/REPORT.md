## 3. С какими сложностями столкнулись

1. **Сложность:** Понимание требований к модификатору `tailrec`. Если после рекурсивного вызова выполняются дополнительные арифметические операции (например, `n * factorial(n - 1)`), рекурсия перестает быть хвостовой, и компилятор выдает предупреждение.
   - **Решение:** Добавлен параметр-аккумулятор `accumulator: Long = 1L`, что позволило передать результат промежуточного умножения в следующий вызов `factorial(n - 1, accumulator * n)` в виде последнего действия функции.

2. **Сложность:** Разница между корутинными строителями `launch` и `async`.
   - **Решение:** `launch` используется для сценариев «fire and forget», возвращая объект `Job` без возврата значения, тогда как `async` возвращает `Deferred<T>`, позволяющий получить результат вычислений через вызов приостанавливающего метода `.await()`.

## 5. Ответы на контрольные вопросы для защиты

### 1. В чём разница между `val` и `var`?
**Ответ:** `val` (value) объявляет неизменяемую (read-only) ссылку, значение которой присваивается один раз и не может быть переопределено. `var` (variable) объявляет изменяемую переменную, значение которой можно перезаписывать в ходе выполнения программы. В соответствии с Kotlin Best Practices рекомендуется всегда отдавать приоритет `val`.

### 2. Что такое null-безопасность и как она реализована в Kotlin?
**Ответ:** Null Safety — это встроенный механизм системы типов Kotlin, исключающий появление ошибок времени выполнения `NullPointerException` (NPE). В Kotlin типы по умолчанию не могут принимать значение `null` (`String`). Чтобы разрешить переменной содержать null, необходимо явно указать знак вопроса (`String?`). При работе с nullable-типами применяются операторы безопасного вызова `?.`, оператор элвис `?:` (значение по умолчанию) и оператор утверждения non-null `!!`.

### 3. Что такое `tailrec` и когда его следует использовать?
**Ответ:** Модификатор `tailrec` инструктирует компилятор оптимизировать рекурсивную функцию в обычный цикл. Это допустимо, когда рекурсивный вызов является самой последней операцией перед возвратом значения (хвостовая рекурсия). Это защищает приложение от ошибки переполнения стека памяти `StackOverflowError` при глубокой вложенности рекурсии.

### 4. Чем `filter` отличается от `filterNotNull`?
**Ответ:** `filter` принимает предикат `(T) -> Boolean` и возвращает список элементов того же типа `List<T>`, удовлетворяющих условию. `filterNotNull` вызывается на коллекции nullable-элементов `List<T?>` и возвращает коллекцию `List<T>`, гарантированно не содержащую элементов `null`, выполняя автоматическое приведение типов на уровне компилятора.

### 5. Что такое функции высшего порядка? Приведите пример.
**Ответ:** Функции высшего порядка (Higher-Order Functions) — это функции, которые принимают другие функции в качестве аргументов или возвращают функцию в качестве результата. Пример: `list.map { it * 2 }` или `fun calculate(a: Int, b: Int, operation: (Int, Int) -> Int): Int = operation(a, b)`.

### 6. Что такое корутины и зачем они нужны?
**Ответ:** Корутины (Coroutines) — это легковесные потоки выполнения (green threads), управляемые рантаймом Kotlin, а не операционной системой. Они позволяют писать асинхронный и неблокирующий код в последовательном (императивном) стиле без использования громоздких обратных вызовов (callbacks) и RxJava. На одном потоке ОС могут выполняться тысячи корутин без существенных затрат памяти.

### 7. В чём разница между `launch` и `async`?
**Ответ:** 
- `launch` запускает новую корутину без возвращения полезного результата. Возвращает объект `Job`, позволяющий управлять жизненным циклом (отменять, ожидать завершения `join()`).
- `async` запускает корутину, которая производит вычисление некоторого значения, и возвращает интерфейс `Deferred<T>` (наследник `Job`). Для извлечения результата вызывается приостанавливающая функция `.await()`.

### 8. Что такое `suspend`-функция?
**Ответ:** Функция, помеченная ключевым словом `suspend`, является приостанавливаемой. Она может быть временно «поставлена на паузу» без блокировки потока операционной системы (например, во время сетевого запроса или ожидания `delay`), а затем возобновлена на том же или другом потоке. `suspend`-функцию можно вызывать только из другой `suspend`-функции или из блока билдера корутины.

### 9. Как работает `groupBy` в Kotlin?
**Ответ:** Функция `groupBy` принимает функцию-селектор ключа `(T) -> K`, итерируется по элементам исходной коллекции и строит словарь `Map<K, List<T>>`, где каждый ключ ассоциирован со списком всех элементов, для которых селектор вернул этот ключ.

### 10. Что такое `data class` и зачем он нужен?
**Ответ:** `data class` (класс данных) в Kotlin предназначен для хранения состояния. Компилятор автоматически генерирует для него методы:
- `equals()` и `hashCode()` на основе свойств конструктора;
- `toString()` в человекочитаемом виде: `Person(name=Анна, age=25)`;
- метод копирования `copy()` для безопасного создания клонов с частичным изменением полей;
- компонентные функции `component1()`, `component2()` для механизма деструктуризации (destructuring declaration).
