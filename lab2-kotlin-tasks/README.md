# Kotlin Tasks — решение задач по языку Kotlin

## Описание проекта
Проект содержит реализацию практических задач по языку программирования Kotlin в рамках дисциплины «Программирование мобильных устройств». 

В ходе работы детально исследованы и применены:
1. **Базовый синтаксис:** функции, условные ветвления `when`, циклы и оптимизированная хвостовая рекурсия (`tailrec`).
2. **Механизмы Null Safety:** безопасные вызовы (`?.`), элвис-оператор (`?:`), преобразование `toIntOrNull()`.
3. **Коллекции и функциональное программирование:** функции высшего порядка (`map`, `filterNotNull`, `groupBy`, `maxByOrNull`, `average`).
4. **Асинхронное программирование (Coroutines):** приостанавливаемые функции (`suspend`), корутинные билдеры `runBlocking` и `async`, параллельная обработка задач.
5. **Дополнительный блок повышенной сложности:** парсинг и агрегация смешанного пользовательского ввода (`processUserInput`).

---

## Архитектура и стек технологий
- **Язык программирования:** Kotlin 2.0 (JVM 17)
- **Система сборки:** Gradle (Kotlin DSL)
- **Библиотека асинхронности:** `kotlinx-coroutines-core:1.8.1`
- **Фреймворк тестирования:** JUnit Jupiter 5.10.2

---

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/TheLegendMaster2023/mobile-dev-labs.git
   ```
2. **Перейдите в директорию лабораторной работы:**
   ```bash
   cd mobile-dev-labs/lab2-kotlin-tasks
   ```
3. **Запустите приложение и демонстрацию решений:**
   ```bash
   ./gradlew run
   ```
4. **Запустите автоматические юнит-тесты:**
   ```bash
   ./gradlew test
   ```
